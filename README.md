# Cheatglobal Browser

Yenilikçi ve modern web tarayıcısı. Electron framework kullanılarak geliştirilmiştir.

## Özellikler

- 🎨 Modern ve kullanıcı dostu arayüz
- 📑 Gelişmiş sekme yönetimi
- ⭐ Yer işaretleri sistemi
- 📜 Geçmiş kayıtları
- 🔍 Akıllı adres çubuğu (URL ve arama otomatik algılama)
- 🎯 Hızlı erişim linkleri
- ⚙️ Ayarlar paneli
- 🔒 Güvenli web görüntüleme
- 💳 Krediler sayfası

## Kurulum

1. Node.js'in yüklü olduğundan emin olun
2. Proje klasöründe terminal açın
3. Bağımlılıkları yükleyin:

```bash
npm install
```

## Çalıştırma

```bash
npm start
```

## Geliştirme Modu

```bash
npm run dev
```

## Kullanım

- **Yeni Sekme**: Yeni sekme butonuna tıklayın veya `Ctrl+T`
- **Sekme Kapatma**: Sekme üzerindeki X butonuna tıklayın
- **Geri/İleri**: Toolbar'daki navigasyon butonlarını kullanın
- **Yenile**: Yenile butonuna tıklayın
- **Yer İşareti Ekle**: Adres çubuğundaki yer işareti butonuna tıklayın
- **Geçmiş**: Toolbar'daki geçmiş butonuna tıklayın
- **Ayarlar**: Toolbar'daki ayarlar butonuna tıklayın
- **Krediler**: Toolbar'daki krediler butonuna tıklayın
